# Sitio de Iglesia Río de Gracia · River of Grace Church

Sitio estático bilingüe (ES/EN) de la Iglesia Río de Gracia, Hatillo, Savegre, Costa Rica.

- Textos: `contenido/es.json` y `contenido/en.json`.
- Plantillas: `plantillas/`. Archivos estáticos: `estaticos/`.
- Generar: `python3 construir.py` → carpeta `publico/`.
- Al hacer push a `main`, GitHub Actions genera y publica el sitio en GitHub Pages (riodegraciacr.org).
